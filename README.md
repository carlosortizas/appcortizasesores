# Cortiz Asesores SAS — App de gestión (CORTIZ-APP-V1-20)

Archivos para GitHub Pages:
- index.html  (la app)
- assets/xlsx.full.min.js  (librería para el respaldo en Excel)
- .nojekyll  (evita que GitHub procese el sitio)

## Subir
1. Crea un repositorio en GitHub (ideal: PRIVADO).
2. Sube TODO el contenido de esta carpeta a la raíz (incluida la carpeta assets y el archivo .nojekyll).
3. Settings > Pages > Source: "Deploy from a branch" > Branch: main > carpeta /(root) > Save.
4. En 1-2 minutos queda en https://TU-USUARIO.github.io/NOMBRE-REPO/

## Importante
- Los datos se guardan en el navegador de cada persona (localStorage). NO se comparten entre los 6 usuarios ni entre PC y celular.
- Usa el botón de respaldo (Excel) con frecuencia.
- No guardes claves reales de clientes en esta versión.
